# 2. Variables

## State Variables

Stored permanently on blockchain.

```solidity
uint public age = 20;
string public name = "Suyash";
bool public isActive = true;
```

---

## Local Variables

Inside functions only.

```solidity
function test() public pure {
    uint x = 10;
}
```

---

## Global Variables

```solidity
msg.sender
msg.value
block.timestamp
block.number
tx.origin
```

```solidity

}
```

# 6. Function Modifiers

## Pure

Reads nothing.

```solidity
function add(uint a,uint b)
public
pure
returns(uint)
{
    return a+b;
}
```

---

## View

Reads state.

```solidity
function getAge()
public
view
returns(uint)
{
    return age;
}
```

---

## Payable

Accept ETH.

```solidity
function deposit()
public
payable
{

}
```

# 18. Modifiers

Reusable checks.

```solidity
modifier onlyOwner(){
    require(
        msg.sender == owner,
        "Not Owner"
    );
    _;
}
```

Use:

```solidity
function withdraw()
public
onlyOwner
{

}
```

# 25. Most Important Syntax Patterns

### State Variable

```solidity
uint public count;
```

### Setter

```solidity
function setCount(uint _count)
public
{
    count = _count;
}
```

### Getter

```solidity
function getCount()
public
view
returns(uint)
{
    return count;
}
```

### Require

```solidity
require(condition,"Error");
```

### Mapping

```solidity
mapping(address => uint) balances;
```

### Event

```solidity
emit Transfer(
    msg.sender,
    amount
);
```
