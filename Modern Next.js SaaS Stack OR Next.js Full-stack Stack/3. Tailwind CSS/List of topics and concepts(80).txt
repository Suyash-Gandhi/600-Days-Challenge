# These Concepts Matter More Than Classes

After learning the 60 items above, master these concepts:

### Responsive Design

```
sm:
md:
lg:
xl:
2xl:
```

Example:

```
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4">
```

---

### Hover States

```
hover:bg-blue-600
hover:scale-105
hover:text-white
```

---

### Transitions

```
transition
duration-300
ease-in-out
```

---

### Positioning

```
relative
absolute
fixed
sticky
top-0
left-0
z-10
```

---

### Overflow

```
overflow-hidden
overflow-auto
```

---

### Object Fit (Images)

```

```

---

### Dark Mode

```

```
