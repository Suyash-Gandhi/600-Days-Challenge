---

One important point

I would not think of the 70 as "70 APIs to memorize."

Think of them as 70 questions you should be able to answer.

For example, after Topic 26, you should be able to answer:

> "Where should I put the Client Component?"

After Topic 40:

> "Should this page be static or dynamic?"

After Topic 48:

> "Why is my page making database requests one after another?"

After Topic 60:

> "Can a malicious user bypass my UI and call this mutation directly?"

After Topic 69:

> "Should this operation be a Server Action or an API endpoint?"

That is a much better definition of Next.js proficiency than simply knowing 70 features.
