## 62. `Omit<T>`

`Omit<T, K>` is a built-in TypeScript utility type that creates a new type by removing specific properties from an existing type.

### Basic syntax

```ts
Omit<Type, Keys>
```

 `Type` → the original type
 `Keys` → properties you want to remove

### Example

```ts
type User = {
  id: number;
  name: string;
  email: string;
  password: string;
};

type PublicUser = Omit<User, "password">;
```

Now `PublicUser` becomes:

```ts
type PublicUser = {
  id: number;
  name: string;
  email: string;
};
```

So:

```ts
const user: PublicUser = {
  id: 1,
  name: "Suyash",
  email: "suyash@example.com"
};
```

You cannot include `password`:

```ts
const user: PublicUser = {
  id: 1,
  name: "Suyash",
  email: "suyash@example.com",
  password: "secret" // ❌ Error
};
```

### Omitting multiple properties

Pass a union of keys:

```ts
type User = {
  id: number;
  name: string;
  email: string;
  password: string;
  createdAt: Date;
};

type PublicUser = Omit<User, "password" | "createdAt">;
```

Result:

```ts
type PublicUser = {
  id: number;
  name: string;
  email: string;
};
```

### `Omit` vs `Pick`

They are essentially opposites:

```ts
type User = {
  id: number;
  name: string;
  email: string;
  password: string;
};

type A = Pick<User, "id" | "name">;
// { id: number; name: string }

type B = Omit<User, "email" | "password">;
// { id: number; name: string }
```

`Pick` → keep these properties

`Omit` → remove these properties

### Real-world example

A common use is creating a type for creating a new database record:

```ts
type Product = {
  id: number;
  name: string;
  price: number;
  createdAt: Date;
};

type CreateProduct = Omit<Product, "id" | "createdAt">;

function createProduct(product: CreateProduct) {
  // save product...
}

createProduct({
  name: "Laptop",
  price: 999
});
```

The client doesn't need to provide `id` or `createdAt` because those can be generated by the server.

### How `Omit` works internally

Conceptually, `Omit` is defined using `Pick` and `Exclude`:

```ts
type MyOmit<T, K extends keyof any> =
  Pick<T, Exclude<keyof T, K>>;
```

For example:

```ts
type User = {
  id: number;
  name: string;
  password: string;
};

type SafeUser = MyOmit<User, "password">;
```

`Exclude<keyof User, "password">` removes `"password"` from the keys, and `Pick` keeps everything remaining.

### Key takeaway

```ts
Omit<User, "password">
```

means:

> "Give me the `User` type, but without `password`."

It's particularly useful for API responses, DTOs, database models, form types, and derived types where you want to reuse an existing type while removing a few fields.
