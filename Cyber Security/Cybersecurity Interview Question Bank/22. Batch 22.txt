# Batch 22 — Cross-Domain Cybersecurity Interview Progression


### Beginner (Q2101–Q2115)

Q2101

- Difficulty: Beginner
- Type: Broad Conceptual
- Classification: Theoretical
- Job Roles: Cloud Security Engineer, IAM Engineer, Security Analyst
- Competency: Understanding cloud identity boundaries

Question: Explain the difference between a human identity, a workload identity and a service identity in a cloud environment. Why should they have separate security policies?

- Difficulty: Beginner
- Type: Specific Technical
- Classification: Practical
- Job Roles: Cloud Security Engineer, DevSecOps Engineer
- Competency: Identifying exposed cloud credentials

Q2118

- Difficulty: Intermediate
- Type: Specific Technical
- Classification: Practical
- Job Roles: API Security Engineer, Application Security Engineer
- Competency: Detecting property-level authorization flaws

Question: Consider this Express.js endpoint:

```
app.patch("/api/users/:id", authenticate, async (req, res) => {
  const user = await User.findByIdAndUpdate(
    req.params.id,
    req.body,
    { new: true }
  );

  res.json(user);
});
```

Identify the authorization and mass-assignment weaknesses. Rewrite the security validation approach so users can modify permitted profile fields but cannot change roles, account ownership or administrative flags.
